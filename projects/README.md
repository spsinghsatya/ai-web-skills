# projects/

## Purpose

This folder will hold your actual website projects — the real things you build, as opposed to the learning notes in the other folders. Your `ai-web-lab` Vite project will be pushed to GitHub later and referenced here (a short folder with a README linking to its repository is enough; no need to copy all its code).

## Suggested layout for each entry

```
projects/
└── ai-web-lab/
    └── README.md   # what it is, stack (Vite, ...), link to its GitHub repo, which library resources it uses
```

Related resources: [`../ui-components`](../ui-components), [`../animations`](../animations), [`../3d-experiences`](../3d-experiences).

## Permanent workflow guideline

> "You do not have to download entire repositories into these folders. Often, the best approach is to let the agent inspect the upstream repository, install the required package, and implement only the components you need."

**Inspect the upstream repository → install the required package → implement only the components you need. Never vendor entire repositories.**

This folder holds knowledge, links, notes and templates — not copies of upstream code.
